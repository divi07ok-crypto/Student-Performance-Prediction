# Student Performance Prediction System

## Project Overview
Student Performance Prediction is a Machine Learning based web application designed to predict students' academic performance based on their attendance, study hours, previous marks, and internal marks.

The system provides performance predictions and helps identify students who may need academic improvement.

## Features
- Student Login
- Staff Login
- Student Performance Prediction
- Attendance Analysis
- Study Hours Analysis
- Previous Marks Analysis
- Internal Marks Analysis
- Performance Categories (Good, Average, Poor)
- Prediction History
- User Authentication

## Technologies Used
- Python
- Flask
- Machine Learning
- Scikit-learn
- Pandas
- NumPy
- HTML
- CSS
- JavaScript
- SQLite

## Machine Learning Algorithm
- Classification Model
- Model Training using Scikit-learn

## How to Run the Project

1. Clone the repository.
2. Install the required dependencies.
3. Train the machine learning model.
4. Run the Flask application.
5. Open the application in your browser.

```bash
pip install -r requirements.txt
python train_model.py
python app.py
```

The main objective is to support students and staff by predicting academic performance and identifying areas that require improvement.
